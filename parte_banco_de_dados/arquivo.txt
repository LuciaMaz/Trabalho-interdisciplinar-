Para ligar o site ao banco MySQL local:

1. Inicie o MySQL (o Workbench sozinho é apenas o programa de administração).
2. Execute database.sql no schema portfolios e configure a coluna Portfolio de cada aluno.
3. Inicie o servidor por uma das formas abaixo.

cd parte_banco_de_dados
npm start

npm start --prefix parte_banco_de_dados

ou

cd parte_banco_de_dados
npm install
npm start

Abra o site por http://localhost:3000/. Não abra os HTMLs por file:// nem por outro
Live Server, porque a autorização dos portfólios é feita pelo servidor da porta 3000.

As páginas de login de aluno e pedagógico criam sessões protegidas no servidor.
