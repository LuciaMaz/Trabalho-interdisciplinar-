para ligar a conexão do site para o banco de dados localhost, só executar 
npm start/node server.js

cd parte_banco_de_dados
npm start

npm start --prefix parte_banco_de_dados

ou

cd parte_banco_de_dados
npm install
npm start

como o acesso aos portfólios será restrito optamos por retirar a página de login
